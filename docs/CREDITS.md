# Credits: what our code took from where

The code under `filterbank/` carries no credit, origin or licence comments. This file is the single record of every idea, layout, constant or convention it reuses. Each row names one reused unit. The columns give our file and function (path from the repository root), what was taken, the upstream project with its file, function or specification, and the paper to cite. The equations behind each row are written out per source library in the [math maps](math-maps/README.md), and by topic in [05-algorithms-math.md](reference/05-algorithms-math.md). The plan that set this rule is [06-our-plan.md](reference/06-our-plan.md).

Every row below is **algorithm-only or convention-only reuse**. No upstream source file has been copied into `filterbank/` yet; there is no `filterbank/vendor/` directory. The "Planned reuse" section lists the code the plan intends to vendor next.
